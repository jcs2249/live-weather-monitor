# Live Weather Monitor

A live weather monitoring dashboard built with HTML, CSS, JavaScript, Python, and FastAPI.

## Features

- Search for weather by city
- Live current weather data
- Temperature
- Feels-like temperature
- Humidity
- Wind speed
- Precipitation
- Weather condition descriptions
- Responsive HTML/CSS interface
- FastAPI backend
- Open-Meteo weather data

## Tech Stack

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Python
- FastAPI
- Uvicorn
- HTTPX

### Weather Data

- Open-Meteo API

### Development

- Git
- GitHub
- pytest
